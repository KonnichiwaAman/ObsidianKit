# Changelog

All notable changes to ObsidianKit are documented here. The project follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and uses semantic versioning where practical before 1.0.

## [Unreleased]

### Added

- MIT license and explicit open-source project status.
- Contribution, governance, security, and conduct policies.
- Structured issue forms and pull-request checklist.
- CI coverage for linting, integrity tests, and production builds.
- Automated weekly dependency update proposals.

## [0.1.0] - 2026-08-02

### Added

- Initial public release of the browser-native toolbox.
- Local-first document, image, media, calculator, text, and utility workflows.
- Lazy tool loading, static SEO route generation, consent-gated analytics, and bundle budgets.

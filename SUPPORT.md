# Support

## Getting Help

ObsidianKit is designed to run entirely inside your web browser with zero server uploads.

If you encounter an issue or have questions:

1. **Tool Guides**: Each tool page on [obsidiankit.me](https://obsidiankit.me) includes usage notes and FAQ sections.
2. **Browser Compatibility**: Ensure you are using an up-to-date modern web browser (Chrome, Edge, Firefox, Safari) with WebAssembly and WebGL enabled.
3. **Issue Tracker**: Search [closed and open issues](https://github.com/amandeavor/ObsidianKit/issues) for similar bugs or feature proposals.
4. **New Issues**: Open an issue using our structured issue forms for bug reports or tool proposals.

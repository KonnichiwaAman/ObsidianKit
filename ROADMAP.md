# Roadmap

This document outlines planned improvements and upcoming browser-native tools for ObsidianKit.

## Core Platform
- [ ] **Web Workers for All Long-Running Tasks**: Ensure all client-side processing executes in dedicated web workers to prevent UI thread lag.
- [ ] **Offline PWA Support**: Enhanced service-worker caching for full offline functionality.
- [ ] **Batch Media Queue**: Multi-file batch processing with queue management across image and document tools.

## Planned Tools
- [ ] **EPUB to PDF Converter**: Client-side conversion of e-books using pure JavaScript / WebAssembly.
- [ ] **JSON / YAML / CSV Schema Validator**: Live browser-native JSON schema validation with formatted error diffs.
- [ ] **Audio Waveform Editor**: Browser-based trimming and audio normalization using Web Audio API.
- [ ] **SVG Path Optimizer & Minifier**: Client-side vector optimization using SVGO in-browser.
